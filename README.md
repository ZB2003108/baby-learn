# 宝贝学习乐园 🌈

面向 4 岁小朋友的启蒙学习工作台。纯前端单文件应用，零依赖、可离线运行。

## 五个模块

| 模块 | 内容 |
| --- | --- |
| 🅰️ 字母乐园 | 26 个字母卡片（大小写 + 单词 + 配图），点击调用 Web Speech API 朗读；大小写配对游戏 |
| 🌸 古诗花园 | 8 首经典幼儿古诗，逐字拼音注音，支持单句朗读 / 全诗朗读 / 慢速跟读 |
| 🔢 数字王国 | 0–20 数字认知（中文 + 英文 + 点点可视化）、10 以内加减法随机出题、数数游戏 |
| 🧩 逻辑挑战 | 找规律（AB / ABC / AAB）、图形配对（形状 × 颜色）、比大小（最大 / 最小 / 哪组最多 / 尺寸） |
| 🚀 闯关冒险 | 12 关 × 5 题混合出题，星级结算，13 枚成就徽章墙 |

## 特点

- **单文件交付**：`index.html` 内联全部 CSS / JS / 图形，无外部资源请求
- **语音朗读**：`speechSynthesis`，字母用 en-US、古诗用 zh-CN；音效由 WebAudio 实时合成
- **进度持久化**：`localStorage`（键 `baby_learn_v1`）保存星星、关卡星级、徽章、朗读记录
- **儿童友好**：所有可点元素 ≥ 44px；答错只提示不惩罚，通关至少 1 星，不会卡关
- **响应式**：PC 侧边栏导航 / 移动端底部 Tab（断点 900px）

## 使用方式

**电脑**：双击 `index.html` 即可。

**手机（同一 Wi-Fi）**：双击 `启动手机访问.bat`，窗口里会显示访问地址并自动生成二维码，手机扫码即可。
首次运行 Windows 若弹出防火墙提示，请选择「允许（专用网络）」。

> 浏览器策略要求先轻点一下页面才会出声，这是正常的。

## 部署

仓库推送到 `main` 后，`.github/workflows/deploy.yml` 会自动构建并发布到 GitHub Pages，
首次运行时会自动启用 Pages（`configure-pages` 的 `enablement: true`）。

## 目录

```
index.html                应用本体（唯一必需文件）
serve_phone.py            局域网访问启动器（自动识别 IP、生成二维码）
启动手机访问.bat           双击启动的入口
.github/workflows/        GitHub Pages 自动部署
```
